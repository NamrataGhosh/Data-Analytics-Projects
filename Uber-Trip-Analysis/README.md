# Uber Trip Analysis

##  Project Overview

The Uber Trip Analysis project focuses on analyzing trip data to understand booking patterns, trip status, city-wise performance, payment methods, and other factors related to Uber trips.

The project involves data preparation, analysis, and dashboard development to transform raw trip data into meaningful and easy-to-understand insights.

---

##  Objective

The main objectives of this project are:

- Analyze overall Uber trip and booking patterns.
- Understand trip distribution across different cities.
- Analyze trip status and identify completed and other trip categories.
- Examine the usage of different payment methods.
- Compare trip activity across cities.
- Create an interactive dashboard for exploring trip-related data.

---

##  Dataset

The project uses an Uber trip dataset containing information related to customer bookings and trips.

The dataset includes information related to:

- City
- Trip/Booking Status
- Payment Method
- Trip-related information
- Customer-related information
- Other attributes related to Uber bookings

The raw dataset is available in the `Raw_Dataset` folder.

##  Data Cleaning

The raw dataset was prepared before creating the dashboard.

The data preparation process included:

- Checking the dataset structure.
- Identifying missing values.
- Checking duplicate records.
- Reviewing data types.
- Handling inconsistent or unnecessary data where required.
- Preparing the cleaned dataset for analysis and visualization.

The cleaned dataset is available in the `Cleaned_Dataset` folder.

##  Dashboards

The project includes two interactive dashboards developed using Looker Studio.

### 1. City and Fare Analysis

This dashboard focuses on trip volume, fare amounts, average distance, and city-wise performance.

It includes:

- Total Trips
- Total Fare
- Average Distance
- Average Fare
- Trip Count by City
- Average Fare by City
- City-wise Fare Distribution
- Average Distance vs Average Fare
- City-wise Fare Map

The dashboard helps compare trip activity, distance, and fare patterns across different cities.

### 2. Status and Payment Analysis

This dashboard focuses on booking/trip status and payment methods.

It includes:

- Total Trips
- Completed Trips
- Cancelled Trips
- Total Fare
- Status Count by City
- Status Distribution
- Status by City
- Payment Method by City

The dashboard helps analyze completed, cancelled, and no-show trips and understand payment method usage across different cities.

---

##  Key Analysis Areas

The project focuses on the following areas:

### City Analysis

- Comparison of trips across different cities.
- Identification of cities with higher and lower trip activity.

### Trip Status Analysis

- Analysis of different booking/trip statuses.
- Comparison of completed and other trip categories.

### Payment Method Analysis

- Analysis of the different payment methods used by customers.
- Comparison of payment method usage across trips.

### Overall Trip Analysis

- Overall trip/booking volume.
- Distribution of trips across cities.
- Relationship between trip status, city, and payment method.
