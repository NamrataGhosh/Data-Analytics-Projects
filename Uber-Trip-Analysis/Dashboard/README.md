# Uber Trip Analysis Dashboard

This folder contains the dashboards created for the Uber Trip Analysis project using **Looker Studio**.

The dashboard provides an interactive view of Uber trip data and helps analyze trip patterns, booking status, cities, and payment methods.

##  Dashboard Pages

### 1. Overview

The Overview dashboard provides a summary of the Uber trip data.

It presents key metrics and visualizations related to overall trips, booking status, cities, and payment methods. It helps users get a quick understanding of the overall trip and booking patterns.

### 2. City-wise Trip Analysis

The City-wise Trip Analysis dashboard focuses on comparing Uber trip activity across different cities.

It helps identify differences in trip volume and booking patterns between cities and provides a detailed view of city-wise performance.

##  Dashboard Filters

The dashboard includes interactive filters that allow users to explore the data based on:

- City
- Booking/Trip Status
- Payment Method

These filters make it easier to analyze specific categories and compare different segments of the dataset.

##  Tools Used

- **Microsoft Excel** – Data Cleaning and Preparation
- **Looker Studio** – Data Visualization and Dashboard Development

##  Purpose

The dashboard was created to transform the cleaned Uber trip data into interactive visualizations and make it easier to identify trends, patterns, and differences in Uber trip activity.
